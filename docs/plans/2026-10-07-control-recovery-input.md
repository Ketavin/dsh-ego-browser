# 控制恢复与直接输入

被打断的浏览器操作可能已在网站生效。paused/unsafePause 保持拒绝普通接管与直接 arm，新增显式恢复入口要求可信请求、当前会话、设备身份、精确 hostGeneration 和租约 epoch。旧租约仅允许其所属 live 会话恢复；宿主确认旧所属会话已删除时，新的 live 会话可清理孤儿租约。

恢复先冻结新操作，等待实际旧操作与人工队列结束，再运行隔离环境中的本包 CLI `--stop`。该运行时在清理状态/锁前验证原 PID 已退出且 CDP 端点消失，不确认则失败并保持暂停。成功才轮换 generation、撤销全部旧目标并授予发起设备人工控制；浏览器登录 profile 保留，所有旧页面需重新打开。不会重试旧网页操作，也不自动 arm Agent，继续仍须两阶段提交门。

桌面点击画面后焦点进入不可见的原生输入桥。普通字符、已提交的中文 IME 和纯文本粘贴经既有有序输入队列发送 insertText；快捷键、方向键、回车和退格经成对按键发送，blur 释放。页面/代次/租约改变时未完成组合文本丢弃，结束 IME 的尾随 input 不重复发送。独立草稿保留为手机和后备输入方式。

Google 登录被拒属于其安全浏览器策略。Google 登录页面与使用说明提供邮箱验证码等替代方案及官方帮助链接。普通浏览器登录不会自动同步，不读取个人 Chrome Cookie，不宣称真实账号 OAuth 已验收。
